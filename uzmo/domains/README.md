# UZMO Enterprise Domains

This layer extends the existing UZMO foundation without replacing it.

Domains added in this phase:
- Human Resources Management (HRM)
- Project Management (PM)
- Operations Management

Each domain is methodology-aware and is designed to be orchestrated by UZMO rather than operate as an isolated chatbot.

## Design rules
1. Preserve existing UZMO agents, runtime, orchestrator, memory, tools and integrations.
2. Select a fit-for-purpose approach instead of forcing one methodology.
3. Keep human approvals configurable for consequential actions.
4. Keep methodology definitions as reference metadata; execution logic belongs to agents/workflows.
5. Do not import, modify or depend on ABZEMO AI.
